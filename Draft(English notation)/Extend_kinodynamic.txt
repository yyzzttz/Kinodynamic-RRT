FUNCTION EXTEND_KINODYNAMIC(T, x_target, dt, max_control_effort):
    # T: current tree, containing nodes with state (x, v) where x is position and v is velocity
    # x_target: target state (can be random state x_rand, or x_goal), generally the x_rand sampled in this iteration's external loop
    # dt: time step for trajectory propagation
    # max_control_effort: maximum control input magnitude
    # returns: new node new_node or FAILURE

    # 1. Find the node in the tree closest to x_target (considering both position and velocity)
    x_near ← Nearest(T, x_target)    # x_near contains both position and velocity: (q_near, v_near)

    # 2. Generate a feasible trajectory from x_near towards x_target using dynamics
    # Unlike geometric RRT, we cannot directly steer - we must propagate through dynamics
    trajectory ← Propagate(x_near, x_target, dt, max_control_effort)
    # Propagate generates a control sequence and simulates the system dynamics
    # Returns a trajectory: sequence of states [(x_0, v_0), (x_1, v_1), ..., (x_n, v_n)]

    # 3. Check if the entire trajectory is collision-free and satisfies dynamics constraints
    IF ValidTrajectory(trajectory) == FALSE THEN
        RETURN FAILURE              # Trajectory violates constraints or has collision → extension failed

    # 4. Extract the final state from trajectory as the new node
    x_new ← trajectory.last         # x_new = (q_new, v_new)
    
    # 5. Can proceed, then insert new node into tree
    new_node ← NewNode(x_new)
    new_node.parent ← x_near
    new_node.trajectory ← trajectory    # Store the control sequence and path for later use
    AddNode(T, new_node)

    RETURN new_node                 # Extension successful, return new node, function ends
END FUNCTION

This method function is the extend single-step logic for kinodynamic RRT based on an initialized tree T and a target state x_target.
Input (tree T, target state x_target, time step dt, max control effort), can complete the operation of tree T approaching target state x_target by one step,
will first generate a feasible trajectory using system dynamics and control,
then check if the entire trajectory has collision or violates dynamics constraints,
if invalid, directly exit the method, end this approach operation, and return failure; if valid, normally approach and then put the node, edge, and trajectory into the tree, and return the latest node new_node after stepping.
