FUNCTION EXTEND_KINODYNAMIC(T, x_target, dt, max_control_effort):
    # T: 当前树，包含状态为 (x, v) 的节点，其中 x 是位置，v 是速度
    # x_target: 目标状态（可以是随机状态 x_rand，或 x_goal），一般是此方法外部本轮循环采样的那个 x_rand
    # dt: 轨迹传播的时间步长
    # max_control_effort: 最大控制输入幅度
    # 返回：新节点 new_node 或 FAILURE

    # 1. 找到树中距离 x_target 最近的节点（同时考虑位置和速度）
    x_near ← Nearest(T, x_target)    # x_near 包含位置和速度：(q_near, v_near)

    # 2. 使用动力学从 x_near 向 x_target 生成可行轨迹
    # 与几何 RRT 不同，我们不能直接 steer - 必须通过动力学传播
    trajectory ← Propagate(x_near, x_target, dt, max_control_effort)
    # Propagate 生成控制序列并模拟系统动力学
    # 返回一个轨迹：状态序列 [(x_0, v_0), (x_1, v_1), ..., (x_n, v_n)]

    # 3. 检查整个轨迹是否无碰撞且满足动力学约束
    IF ValidTrajectory(trajectory) == FALSE THEN
        RETURN FAILURE              # 轨迹违反约束或有碰撞 → 扩展失败

    # 4. 从轨迹中提取最终状态作为新节点
    x_new ← trajectory.last         # x_new = (q_new, v_new)
    
    # 5. 可以走，则把新节点插入树中
    new_node ← NewNode(x_new)
    new_node.parent ← x_near
    new_node.trajectory ← trajectory    # 存储控制序列和路径以供后续使用
    AddNode(T, new_node)

    RETURN new_node                 # 扩展成功，返回新节点，函数结束
END FUNCTION

这个方法函数是基于一个初始化的树T和一个目标状态x_target的kinodynamic extend单步步进逻辑。
传入（树T，目标状态x_target，时间步长dt，最大控制量），可以完成树T朝目标状态x_target接近一步的操作，
会先使用系统动力学和控制生成可行轨迹，
然后判断整个轨迹有无碰撞或违反动力学约束，
有碰撞或违反约束直接跳出方法，结束这一个接近操作，并传回failure；无碰撞且满足约束就正常接近然后把节点、边和轨迹放入树內，并传回步进后最新这个节点new_node。
